# StillHere mobile sandbox

React Native + Expo + TypeScript prototype. Clinical Minimal design.

## Screens
- People: monitored individuals, device connectivity
- Person details: wearable connection and motion disclaimer
- Safety alerts: sample SOS event
- Incident details: local "I'm responding" acknowledgment

## Run
```bash
npm install
npx expo start
```
Scan the QR code with Expo Go on a compatible phone, or launch an emulator.

## Boundaries
All names and incidents are fictional. No backend is connected. ACK is stored only in memory and resets when the app restarts. No emergency-service integration or validated medical detection.
